# Superseded

This dual-mode (`enterprise` / `lean`) epic passed Gate 1 and Gate 2 but was never implemented.

It is superseded by **`tri_mode_and_flutter_plugin_devbed`**, which adds the third mode
(`plugin` — the Flutter Plugin Native Devbed) that this epic had listed as a Non-Goal, matching
the Android template's epic of the same name.

Kept for the Gate 1 / Gate 2 decision history only. Do not implement from these files.
